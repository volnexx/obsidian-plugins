# Virtual Linker / Glossary 1.5.3

Наша модификация плагина Virtual Linker для Obsidian.

## Изменения

- Текст виртуальной ссылки сохраняет исходные цвет и оформление во всех состояниях, включая наведение и нажатие. Виртуальная ссылка обозначается только суффиксом-значком.
- В обычные настройки добавлено поле «Исключённые папки с заметками-целями».
- Пути к исключённым папкам задаются по одному на строку; вложенные папки также исключаются.
- Исключение является безусловным: заметки из указанных папок не используются как цели виртуальных ссылок.
- Пути нормализуются, а специальные символы в названиях папок обрабатываются безопасно.

# Virtual Linker / Glossary 1.5.7

Наша модификация плагина Virtual Linker для Obsidian.

## Изменения

- Все названия, разделы, пояснения и варианты выбора в настройках переведены на русский язык.
- Добавлен отдельный раздел «Исключённые папки» с большими многострочными полями.
- «Папки с исключёнными заметками-целями» запрещают использовать названия и псевдонимы заметок из указанных папок.
- «Папки без виртуальных ссылок» запрещают добавлять значки в заметках из указанных папок как в редакторе, так и в режиме чтения.
- Исключения распространяются на вложенные папки; пути указываются по одному на строку.
- Совпавшее словосочетание остаётся исходным текстом редактора: плагин не заменяет его и не назначает ему цвет, оформление или класс ссылки.
- Кликабельной виртуальной ссылкой является только добавленный суффикс-значок, например `✧`.
- Пересекающиеся названия сначала разрешаются в пользу самого длинного совпадения. Например, `плагин опыт` ведёт только на заметку `плагин опыт`, а короткая заметка `опыт` больше не может подменить её после ограничения повторных ссылок.
- Повторные вхождения снова остаются виртуальными ссылками; наличие такой же ссылки или настоящей ссылки раньше в заметке больше не скрывает последующие совпадения по умолчанию.

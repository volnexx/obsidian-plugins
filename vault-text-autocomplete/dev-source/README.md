# Автодополнение текста по хранилищу

Плагин для Obsidian показывает варианты продолжения слов и фраз из текущей
заметки, всего хранилища, внутренних ссылок и пользовательских словарей.

## Главное отличие

Окно подсказок не перехватывает клавиатуру:

- `Enter` создаёт новую строку;
- `Tab` работает в редакторе;
- стрелки, `Home` и `End` перемещают курсор;
- ни одна клавиша не выбирает и не вставляет подсказку.

Подсказки предназначены прежде всего для визуального просмотра. Щелчок мышью
по варианту оставлен рабочим и вставляет выбранный вариант.

## Установка

1. Распакуйте папку `vault-text-autocomplete` в
   `<хранилище>/.obsidian/plugins/`.
2. Перезапустите Obsidian.
3. Включите «Автодополнение текста по хранилищу» в сторонних плагинах.

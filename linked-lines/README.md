# Line Clone Sync

Плагин синхронизирует изменения одинаковых строк между Markdown-заметками Obsidian.

## Основные возможности

- синхронизация точных клонов строки;
- минимальное количество слов для создания новой связи;
- сохранение уже созданной связи при сокращении строки до одного слова, одного символа и полного удаления;
- поддержка удаления строки через `Ctrl+X`;
- рычаг включения и выключения в нижней строке состояния;
- сохранение состояния рычага после перезапуска Obsidian;
- сохранение окончательно удалённых клонов в призрачных заметках плагина «Опыт»;
- отсутствие уведомлений, если совпадений не найдено;
- перенос строк по названию заметки.

## Перенос по названию заметки

Строка вида:

```text
еда – купить яблоки
```

находит существующую заметку `еда.md` и создаёт в её конце строку:

```text
купить яблоки
```

Если такая строка уже существует, она связывается с исходной. Дальнейшее редактирование синхронизируется в обе стороны.

Поддерживаются разделители ` - `, ` – ` и ` — `, а также строки внутри списков и задач.

## Установка

Папка плагина должна содержать:

```text
main.js
manifest.json
styles.css
```

## Призрачные заметки «Опыта»

Начиная с версии `1.2.0`, после полного удаления связанной строки плагин:

1. Удаляет её связанные экземпляры.
2. Повторно проверяет все Markdown-заметки.
3. Если ни одного представления связи не осталось, передаёт точные удалённые строки в `Опыт 0.6.0`.
4. «Опыт» дописывает каждую строку в призрачную заметку соответствующего исходного файла.

Несвязанная строка не архивируется. Если хотя бы один клон остался, призрачные заметки не изменяются.

Текущая версия: `1.2.0`.

# Line Clone Sync

Плагин отслеживает замену одной строки в редакторе и переносит итоговое изменение на её точные копии в других Markdown-заметках.

## Установка

1. Создайте папку `.obsidian/plugins/line-clone-sync`.
2. Скопируйте в неё `manifest.json`, `main.js` и `styles.css`.
3. Перезапустите Obsidian или перезагрузите плагины.
4. Включите `Line Clone Sync` в разделе сторонних плагинов.

## Ограничение первой версии

Автоматически обрабатывается замена содержимого ровно одной строки. Вставка или удаление перевода строки, а также одновременное изменение нескольких строк не распространяются — это намеренная защита от массовых ошибочных замен.

## Отмена

Команда `Отменить последнюю синхронизацию строк` восстанавливает все заметки, изменённые последней операцией. История хранится только до перезапуска Obsidian.


## Исправление уведомлений

Уведомление «Точных копий строки не найдено» отключено. При отсутствии совпадений плагин работает молча.

## Удаление всей строки

`Ctrl+X` без выделения распознаётся как удаление текущей строки вместе с переводом строки. Если строка уже связана с копиями либо сама подходит для создания связи, соответствующие строки в связанных заметках удаляются полностью, а не превращаются в пустые строки.


## Исправление постоянной связи
Связь больше не сбрасывается при обновлении второй открытой заметки, переключении листов или временной задержке обновления файла. После создания связи многословной строкой она сохраняется при сокращении до одного слова и одного символа.

## Минимальное количество слов

В настройках доступен пункт **«Минимальное количество слов»**.

Он определяет, со скольких слов строка может создать новую связь с точными копиями. По умолчанию установлено `2`.

Ограничение действует только при создании связи. После создания связи строку можно сокращать до одного слова, одного символа или удалять полностью.


## Перенос строки по названию заметки

Строка вида `Название заметки – текст` переносит `текст` в конец заметки `Название заметки.md`. Исходная строка и перенесённая строка остаются связанными: изменение любой стороны синхронизирует другую. Название заметки должно быть уникальным в хранилище.


## Исправление создания строки

Маршрутная строка теперь создаётся и при вводе с пустой строки. Поддерживаются разделители:

- ` – `
- ` - `
- ` — `

Также поддерживаются строки задач и списков, например:

```text
- [ ] еда – купить яблоки
```

В `еда.md` будет добавлено:

```text
купить яблоки
```

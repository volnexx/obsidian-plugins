# Rick UI 0.2.0

Визуальный слой для Obsidian, собранный по повторяющимся особенностям приборных интерфейсов из предоставленных пользователем кадров.

## 0.2.0
- усиленные рамки крупных панелей;
- отдельные приборные заголовки;
- сегментированные кнопки и вкладки;
- аппаратное состояние нажатия;
- красные/жёлтые аварийные состояния;
- индикатор работы в строке состояния;
- более плотное оформление поиска и палитры команд;
- переработанные переключатели и поля ввода;
- дополнительные угловые маркеры экранов.

Настройки находятся в `Настройки → Rick UI`.

# Rick UI 0.3.0

Визуальный слой для Obsidian, построенный по повторяющимся особенностям интерфейсов из предоставленных кадров Rick and Morty.

## Что изменено в 0.3.0

- полностью переработана визуальная система по исходным кадрам;
- основной вид теперь строится вокруг полупрозрачных световых экранов, а не общего CRT-эффекта;
- двойные и внутренние рамки крупных окон;
- срезанные формы карточек и панелей;
- отдельные красные аварийные капсулы;
- янтарные служебные метки;
- сегментированные шкалы и ползунки;
- панели поиска и команд оформлены как отдельные голографические дисплеи;
- новые вкладки в форме приборных карточек;
- переработаны боковые панели, проводник файлов, настройки, переключатели, меню и строка состояния;
- техническая сетка теперь находится только на вспомогательных панелях и не накладывается на текст заметок;
- строки экрана стали локальным необязательным эффектом и по умолчанию выключены;
- добавлена световая дымка и медленный проход света по крупным экранам;
- добавлены варианты цвета: бирюзовый, пурпурный и зелёный;
- сохранена совместимость с Minimal через переменные Obsidian вместо замены самой темы.

Настройки: `Настройки → Rick UI`.

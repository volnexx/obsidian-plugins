# Rick UI 0.3.1

Визуальный слой для Obsidian по повторяющимся особенностям интерфейсов из предоставленных кадров Rick and Morty.

## Исправление 0.3.1

- исправлен полный отказ оформления при потере класса `body.rick-ui`;
- плагин теперь сам повторно подключает `styles.css`, а не полагается только на автоматическую загрузку Obsidian;
- класс оформления и параметры восстанавливаются после готовности рабочего пространства, изменения компоновки и возврата фокуса;
- наблюдатель восстанавливает класс, если его сбрасывает тема или другой слой интерфейса;
- ключевые цвета дополнительно задаются напрямую из JavaScript, поэтому включённый плагин больше не может выглядеть полностью как обычная тема даже при проблеме с CSS;
- добавлена команда `Rick UI: Переприменить оформление`;
- визуальная система 0.3.0 сохранена без упрощения.

Настройки: `Настройки → Rick UI`.

# Переход к повторению

Плагин связывает «Повторение терминов» с Jump to Link, не меняя ни один из двух плагинов.

## Что становится ссылкой

- В определении `**Термин — определение**` ссылкой становится распознанное жирное определение. Она открывает карточку именно этого определения.
- Заголовок становится ссылкой на карточку перечня, только если «Повторение терминов» распознаёт под ним не меньше двух пунктов.
- `**Термин**` внутри перечня не становится отдельной ссылкой: у него нет отдельной карточки определения.

Правила полностью совпадают с «Повторением терминов»: нужны закрытая пара `**`, длинное тире `—`, а перечень завершается двумя пустыми строками, обычным текстом или новым заголовком. Порядок пунктов остаётся ручным.

## Как это работает

- Обычный клик по виртуальной ссылке открывает большую карточку повторения в центральной вкладке.
- Команда Jump to Link видит эти цели вместе с обычными ссылками в режиме чтения, Live Preview и чистом исходном режиме.
- В режиме чтения и Live Preview цели являются настоящими элементами `<a>`, поэтому Jump to Link находит их своим обычным способом.
- Для чистого исходного режима плагин аккуратно добавляет цели к списку подсказок Jump to Link на время команды и восстанавливает исходные функции при отключении.

## Требования

- «Повторение терминов» версии 0.36.0 или новее.
- Jump to Link версии 0.5.16. Если Jump to Link отключён, прямой клик продолжает работать, но буквенные подсказки не появляются.

## Установка вручную

1. Распаковать папку `jump-to-recall` в `<хранилище>/.obsidian/plugins/`.
2. Перезапустить Obsidian.
3. Включить «Повторение терминов», Jump to Link и «Переход к повторению».

Настройки и сочетания клавиш Jump to Link остаются прежними.

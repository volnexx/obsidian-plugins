# Style Settings — 8 тем

Централизованная версия нашего плагина цветового цикла для Obsidian.

- ID: `style-settings-color-cycle`
- Версия: `2.1.0`
- 8 опорных тем: красная, оранжевая, жёлтая, зелёная, голубая, синяя, фиолетовая, розовая.
- По умолчанию тема держится 60 секунд, переход длится 8 секунд.
- На ПК основные поверхности принудительно остаются чисто чёрными.

Исходный репозиторий плагина: `volnexx/style-settings-plugin`.

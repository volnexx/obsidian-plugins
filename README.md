# Obsidian Plugins

Единый репозиторий пользовательских плагинов Obsidian.

## Структура

- `registry.json` — единственный реестр, который читает Updater Plugin.
- `experience/` — плагин «Опыт».
- `priority-recall/` — интервальное повторение.
- `resource-monitor/` — монитор ресурсов.

Каждая папка плагина должна содержать как минимум `manifest.json` и `main.js`; `styles.css` добавляется при необходимости.

## Правило обновлений

Новые версии наших плагинов публикуются прямо в соответствующую папку этого репозитория. Одновременно обновляется `version` в `manifest.json` и соответствующая версия в `registry.json`.

Пустые или ещё не перенесённые плагины не добавляются в `registry.json`, чтобы Updater Plugin не пытался устанавливать несуществующие файлы.

## Updater Plugin

Updater Plugin использует один источник: `volnexx/obsidian-plugins`. Перед установкой найденных обновлений он создаёт резервную копию хранилища и сохраняет предыдущую версию каждого обновляемого плагина для отката.

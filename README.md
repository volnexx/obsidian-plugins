# Obsidian Plugins

Единый репозиторий наших пользовательских плагинов Obsidian.

## Рабочие плагины

Эти проекты уже содержат реальные файлы плагина и могут участвовать в обновлении через `registry.json`:

- `activity/` — статистика времени и открытий заметок с программным интерфейсом для других плагинов.
- `experience/` — «Опыт».
- `parsing/` — разбор и распределение строк по заметкам через Omnisearch.
- `priority-recall/` — интервальное повторение.
- `search/` — совместимая замена Omnisearch со строгим приоритетом точного совпадения названия.
- `resource-monitor/` — монитор ресурсов.
- `updater-plugin/` — единая кнопка обновления с резервной копией и откатом.
- `virtual-linker/` — наша модификация Virtual Linker: виртуальные ссылки без изменения цвета текста и с исключением папок с заметками-целями.
- `vps-sync/` — VPS Sync: зашифрованная синхронизация всего хранилища через собственный VPS.

## Наши остальные проекты

Эти папки уже заведены в общем репозитории, но их актуальные исходники ещё не найдены в доступных файлах или старых GitHub-репозиториях. Поэтому они намеренно не включены в `registry.json` до появления реальных `main.js` и `manifest.json`:

- `perspectivism/` — Perspectivism.
- `interactive-formula/` — интерактивные формулы.
- `linked-lines/` — синхронизация строк.
- `line-to-note/` — строка → заметка.
- `vault-autocomplete/` — автодополнение по хранилищу.
- `style-settings-plugin/` — наша модификация Style Settings / управления темами.
- `token-plugin/` — подсчёт токенов.

## Реестр обновлений

`registry.json` — единственный реестр, который читает Updater Plugin. В него попадает только плагин, у которого в репозитории реально есть рабочие `manifest.json` и `main.js`; `styles.css` добавляется при необходимости.

## Правило дальнейшей работы

Когда мы изменяем любой наш плагин, новая версия публикуется прямо в соответствующую папку этого репозитория. Одновременно обновляются `version` в `manifest.json` и версия в `registry.json`.

Updater Plugin использует `volnexx/obsidian-plugins` как единый источник. Перед установкой найденных обновлений он создаёт резервную копию хранилища и сохраняет предыдущую версию каждого обновляемого плагина для отката.

# Updater Plugin 0.7.0

Использует единый центральный источник `volnexx/obsidian-plugins`.

Updater загружает `registry.json`, сопоставляет записи с установленными плагинами и скачивает файлы только тех плагинов, для которых есть обновление.

Текущая рабочая ветка реестра: `centralize-plugins`.


## 0.4.1

После установки новой версии обновляется внутренний кэш manifest.json Obsidian и открытый список сторонних плагинов.


## 0.6.0

- Кнопка отката в заголовке Markdown-заметки.
- Откат к последней резервной копии перед обновлением.
- Автоматический снимок текущего состояния перед откатом.
- После отката кнопка превращается в возврат вперёд.
- Updater Plugin сохраняется текущим при восстановлении.
- После восстановления Obsidian автоматически перезагружается.


## 0.7.0

- Updater автоматически сканирует все папки верхнего уровня центрального репозитория.
- `registry.json` больше не задаёт список плагинов.
- Папка считается плагином при наличии `manifest.json` и `main.js`.

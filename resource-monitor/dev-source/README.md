# Монитор ресурсов

Русскоязычное дополнение для настольного Obsidian.

## Четыре графика

1. **ОЗУ** — фактическая память текущего процесса Obsidian: весь процесс, куча JavaScript и внешняя память.
2. **ЦП** — нагрузка Obsidian и общая нагрузка компьютера. Доля Obsidian приведена к полной мощности всех логических ядер.
3. **Видеокарта** — общая нагрузка NVIDIA, занятая видеопамять и температура. Показатели считываются через `nvidia-smi` каждые две секунды.
4. **SSD** — общая скорость чтения и записи физических накопителей Linux по `/proc/diskstats`.

Для всех графиков доступны промежутки 1, 5 и 15 минут. История существует только в оперативной памяти и сбрасывается после закрытия Obsidian.

## Разбивка по дополнениям

Ниже графиков остаётся приблизительная разбивка живых JavaScript-выделений по дополнениям.

Верхнее значение ОЗУ измеряется напрямую. Нижние проценты — не доли от всей ОЗУ: это выборка V8, которая помогает увидеть активных потребителей JavaScript-памяти. Память Chromium, изображений, нативных библиотек и нераспознанного кода остаётся в строке «Obsidian и нераспознанное» либо не входит в выборку.

## Установка

1. Распакуйте архив в папку `<хранилище>/.obsidian/plugins/memory-monitor-ru/`.
2. Перезапустите Obsidian или перезагрузите дополнения.
3. Включите «Монитор ресурсов» в настройках сторонних дополнений.
4. Откройте панель значком графика в левой ленте или командой «Монитор ресурсов: Открыть монитор ресурсов».

Первые доли дополнений обычно появляются через 10–30 секунд. Чем дольше и разнообразнее обычная работа, тем полезнее выборка, но четыре графика начинают собирать историю сразу.

Дополнение не читает заметки и не отправляет данные. Для графика SSD оно читает только системные счётчики Linux, а для видеокарты запускает локальную команду NVIDIA.
